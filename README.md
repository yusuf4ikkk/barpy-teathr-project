# Театр Барпы — сайт на Django

Полностью серверный сайт: афиша, схема зала с выбором мест, заказ билетов через **WhatsApp**, админка для кассира.

## Запуск

```bash
./setup.sh            # создаст venv, поставит зависимости, применит миграции, зальёт демо-данные и запустит сервер
```

Или вручную:

```bash
pip install -r requirements.txt
python manage.py migrate
python manage.py seed_demo --with-admin   # демо-контент + админ admin / admin12345
python manage.py runserver
```

* Сайт — http://127.0.0.1:8000/
* Админка — http://127.0.0.1:8000/admin/ (**сразу смените пароль**, а для боевого сайта создайте своего пользователя: `python manage.py createsuperuser`)

## Как работает покупка

1. Зритель выбирает спектакль → сеанс → места на схеме зала, вводит имя и телефон.
2. Сервер атомарно бронирует места (двойная продажа невозможна — уникальное ограничение в БД) и создаёт заказ `BP-XXXXXX`.
3. Открывается страница заказа и **автоматически — чат WhatsApp кассы** с готовым сообщением (спектакль, дата, места, сумма, имя, телефон).
4. Бронь держится N минут (по умолчанию 30). Не оплатили — места освобождаются сами.
5. Кассир в админке: **Заказы → «Ответить →»** открывает WhatsApp-чат с клиентом и текстом с реквизитами. После оплаты — действие **«Подтвердить оплату»**: заказ становится «Оплачен», а страница заказа у клиента превращается в билеты (их можно распечатать).
6. «Отменить заказ» сразу освобождает места. В «Билетах» можно отмечать вход в зал.

## Первым делом в админке → «Настройки сайта»

* **Номер WhatsApp кассы** (по умолчанию стоит заглушка 996779949710 — замените!),
* реквизиты оплаты и шаблон ответа клиенту,
* телефон, адрес, режим работы, соцсети, карта, текст «О театре», правила посещения,
* время брони и максимум мест в заказе.

Содержимое (спектакли, сеансы, труппа, новости, залы) тоже редактируется в админке. Демо-контент — пример, замените своим.

## Деплой

```bash
export DJANGO_DEBUG=0
export DJANGO_SECRET_KEY='длинная-случайная-строка'
export DJANGO_ALLOWED_HOSTS='example.kg'
export DJANGO_CSRF_TRUSTED_ORIGINS='https://example.kg'
python manage.py collectstatic --noinput
python manage.py migrate
gunicorn config.wsgi
```

* Загруженные картинки лежат в `media/` — отдавайте её через nginx (или подключите S3).
* По умолчанию SQLite; для нагрузки лучше PostgreSQL (измените `DATABASES` в `config/settings.py`).
* Если HTTPS пока нет, добавьте `DJANGO_SSL_REDIRECT=0`.

## Структура

```
config/            настройки проекта
theatre/models.py  Hall, Performance, Session, Order, Ticket, Actor, News, SiteSettings
theatre/views.py   страницы, бронирование, страница заказа
theatre/admin.py   админка (+ sites.py — дашборд)
templates/         base.html, theatre/*.html, admin/*
static/            css/site.css, js/*, admin_theme/barpy-admin.css
theatre/tests.py   тесты (python manage.py test)
```
